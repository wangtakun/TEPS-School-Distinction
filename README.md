# Replication Materials for _School Distinction_

Replication materials for the paper:

**School Distinction: How Social Position Shapes Parenting Practices and Educational Choice**  
*學校區分：社會位置如何形塑家長之教養實作與教育選擇*

**Author:** Takun Wang (王大鯤)

The paper is currently under review with minor revisions. Full information will be added following publication.

## Contents

- `1-Prepare.qmd` / `1-Prepare.pdf` — Data preparation and cleaning. The Quarto document contains the code used to prepare the data for analysis; the PDF provides the rendered output.
- `2-Analyze.qmd` / `2-Analyze.pdf` — Data analysis. The Quarto document contains the code used for the statistical analyses; the PDF provides the rendered output.

## Data

The analysis uses data from the Taiwan Education Panel Survey (TEPS). Raw survey data are not included in this repository.
